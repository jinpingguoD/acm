也就是单调栈的升级版，但原理上面都差不多，都是用出队与入队来解决区间中最大最小值的问题，区别在于单调栈只能用来解决一整个区间的问题，这是因为当前已经看过的元素不能从栈底被拿出，因此我们可以采用双端队列来解决这个问题
```cpp
deque<pair<int, int>>l1;
vector<int>l2;
int n, k;
其中l1是双端队列 l2是原数组
n代表有n个数，k代表记录这一个区间中的最值
rep(i, 1, n) {
	这一步判断当前的队列中最前面的值是否超过当前区间的范围
	如果超过那么直接弹出，当然只检测一下
	if (!l1.empty() && i - l1.front().second >= k) {
		l1.pop_front();
	}
	不断更新，维护当前这个队列
	while (!l1.empty() && l2[i] >= l1.back().first) {
		l1.pop_back();
	}
	把新元素假如队列
	l1.push_back({ l2[i],i });
	最后就可以记录一下当前区间的最值
}
```

简单来说就是对于一个数组中任意一个数求出来他的下一个或者上一个大于或者小于的数，也就是方便查询的一个数据结构
```cpp
在这里l1代表原数组，l2是栈本身，l3是对于原数组的每一个下标说查找当前想要得到结果的下标
for(int i=n-1;i>=0;i--){
		while(!l2.empty()&&l1[l2.top()]<=l1[i]){
		//如果当前栈不是空的或者新加进来的元素大于前面已经加进来的元素
		//那么把前面加进来的元素直接弹出，保证后面元素所查找的值
			l2.pop();
		}
		//如果当前栈是空的，说明已经全部弹出，这个点要找到的相对应的值应该就是其本身
		//这时候用一个简单的运算符表示
		l3[i]=l2.empty()?-1:l2.top();
		//弹进去这个元素
		l2.push(i);
	}
```
本代码写的是这个数组中查找对于数组元素来说在他后面比他大的元素的下标
如果想要反过来，查找每一个数组元素前面比他大的元素下标，那么直接把循环从零开始就行了
或者说想要找到比当前元素小的下标，只需要修改一下判断条件就行

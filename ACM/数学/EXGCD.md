先看前置的知识点，对于任意一个这样的式子 ax ≡ 1(mod b)叫做线性同余方程
也就是整数ax除以b所得的余数是1，式子的解叫做a关于模b的乘法逆元
如果这个式子变一下形式，那么就是对   ax+by=1   求解
首先方程不一定有解，存在整数解的充要条件是a与b互质，也就是两个数的最大公因数为1
那么现在怎么求出来这个方程的解，就是EXgcd（也就是扩展欧几里得算法）
代码如下：
```cpp
int exgcd(int a, int b, int &x, int& y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b, a % b, x, y);
    int t = x;
    x = y;
    y = t - (a / b) * y;
    return d;
}
```
原理不在阐述，使用的时候可以传入任意的x y，函数返回的值是a b的最大公因数。
经过这样一次修改之后，x y就是原方程的一个特解，要想求通解，那么会是这个形式
X1=x+b* t
Y1=y-a* t
t为任意整数
这是特殊形式，一般来说出现的形式都是 ax ≡ c(mod b)，这样的情况
对于这种情况，求出来  d = gcd（a，b），如果最大公因数不能整除c，那么方程无解，如果有解，那么先求出来相对应的x y，再乘上c/d，这样就是一个特解的形式
以及最后
x1 = x​+ (b/d)* t
y1 = y- (a/d)* t
这是此方程的通解
那么exgcd最常见的方面就是给定一个这样的二元一次不定方程问有没有整数解（裴蜀定理），如果有求出来相对应的整数解（exgcd）

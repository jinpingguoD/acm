传统的方法用来判断素数（质数）是非常慢的，而埃式筛与线性筛能很好地解决这个问题，不过不能实现单一个数的迅速判断，而是找出来一个区间中的素数
假如在[1,N]区间中找到素数的个数，首先任何一个数如果不是素数那么一定有相对应的素数因子，也就是对于任意一个合数都有至少一个素数作为其因子。那么这样来看，我们可以直接遍历1到n，先把素数标记出来，以这个素数开始，把这个素数的倍数进行标记（不大于n），保证标记出来的这些数一定是合数，这样就能实现时间复杂度是 O(N log log N) 的情况下进行快速找出来素数
代码：
```cpp
vector<int>l1;
bool l2[1000000];
void Prime(ll n) {
    rep(i, 2,  n) {
	    //从2开始进行枚举
        if (!l2[i]) {//找到一个素数之后直接标记出来他的倍数
            l1.push_back(i);
            ll k1 = i;
            while (k1 <= n) {
                l2[k1] = 1;
                k1 += i;
            }
        }
    }
}
```
当然还有一种在埃及筛的基础之上的方法能实现在O(N)的情况下进行操作，线性筛（欧拉筛）
#####  注意，线性筛一般情况下因为常数导致在1e7往下的情况基本上都是埃及筛使用较快
首先能发现在埃式筛中会出现一个合数被多个他的质因子反复标记的情况（例如6），这个时候可以优化一下，变成一个合数只被他自己的最小质因子标记一次，这样就能实现效率上面的提升
代码：
```cpp
void Prime(ll n) {
    rep(i, 2,  n) {
        if (!l2[i]) {
            l1.push_back(i);
        }
        for (auto it : l1) {
            ll k1 = it * i;
            l2[k1] = 1;
            if (i % it == 0) {
                break;
            }
            在这里解释一下代码
            首先如果it(也就是一个素数)能够被i整除，说明it是i的最小质因子
            此时如果选择向后面进行遍历，得到的合数的最小质因子一定不是后面遍历的质数
            因为这时候的合数已经有一个最小质因子找到了
            那么这个时候合数进行的乘法得到的合数的最小质因子也一定是前者的最小质因子
            如果没有被整除，说明当前这个质数是乘过去的合数(k1)的最小质因子
            因此代码结构如上
        }
    }
}
```

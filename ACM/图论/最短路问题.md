也就是根据一个图，询问其中一个点至另一个点的路径最小值
## DIJ
算法本质就是通过贪心实现构建最短路的作用。需要注意的是，不能用于有负权的图中，以及一次只能实现计算一个点到所有边的长度的需求
```cpp
vector<vector<pair<int, int>>>l1;
int dist[10005];
void DIJ(int n) {
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>>l2;//小根堆，实现最短边在前
    l2.push({ 0,n });//先把长度放在前面，排序时优先排前面的数据
    while (!l2.empty()) {
        int k1 = l2.top().first;
        int k2 = l2.top().second;
        l2.pop();
        if (k1 != dist[k2]) {//添加进小根堆的时候添加的是当前的距离，如果出现不一样说明有更小的出现，直接跳过
            continue;
        }
        for (auto it : l1[k2]) {
            if (dist[it.second] > dist[k2] + it.first) {
                dist[it.second] = dist[k2] + it.first;
                l2.push({ dist[it.second],it.second });
            }
        }
    }
}
```
时间复杂度：O((V+E)logV)
## Floyd
比DIJ不同的地方在于这个是实现对于任意一个点到另一个点的最短路的计算
当然，时间非常慢，只适用于n<=400或者500的情况
需要注意的是，读入的时候就直接把重边处理一下实现记录的边都是最小值
```cpp
	初始化
	for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) dist[i][j] = 0;
            else dist[i][j] = INF;
        }
    }
    读入的特殊处理
	for (int i = 1; i <= m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        dist[u][v] = min(dist[u][v], w); // 有向图
        // dist[v][u] = min(dist[v][u], w); // 如果是无向图，加上这行
    }
	for (int k = 1; k <= n; k++) {//类似于区间DP的三重循环
		实现思路就是计算是否有中间点能够实现两个点相连的距离缩短
        for (int i = 1; i <= n; i++) {
            if (dist[i][k] == INF) continue;
            for (int j = 1; j <= n; j++) {
                if (dist[k][j] == INF) continue;
                if (dist[i][j] > dist[i][k] + dist[k][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
```
时间复杂度：O（N^3）
## SPFA
能够处理负权边以及判断图中是否出现负环（一个环的权值之和小于0）
```cpp
vector<pair<int,int>> G[N];
int dist[N], cnt[N];
bool inq[N];                // 标记是否在队列中（优化，防止重复入队）
// 返回false表示存在负环，true表示正常跑完
bool SPFA(int s, int n) {
    memset(dist, 0x3f, sizeof(dist));
    memset(cnt, 0, sizeof(cnt));
    memset(inq, false, sizeof(inq));
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    inq[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = false; // 出队，取消标记
        for (auto [v, w] : G[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                cnt[v] = cnt[u] + 1; 
                // 这里的cnt含义是：到达v的最短路径包含的边数
                // 如果边数 >= n，说明经过了n+1个点，根据鸽巢原理，必然有环
                // 由于距离还在更新减小，说明这个环一定是负环！
                if (cnt[v] >= n) return false; 
                // 只有不在队列中才入队，避免队列里存在大量冗余
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
    return true;
}
```
因为关于SPFA的时间复杂度有时候能达到O（n* m），因此不出现负权边或者判断负环的情况下尽量不要使用SPFA，可能会卡数据

0/1背包
也就是n个物品，每一个物品只能选一次，求出价值最大
因此可以看作这样的情况：对于每一个物品来说，都有选或者不选两种情况
如果选择，那么背包容量减少，价值上升；反之容量不变，价值不变；
然后从这两种选择中选择最大的那一个
这其中也有两种写法（二维与一维）
二维：其中dp[] []的第一层表示此时是那个物品，第二层表示剩下的容量
那么装下一个物品的硬性要求肯定是此时的空间还能装下，所以说判断此时应不应该选择这个物品就要看第二维中剩余的容量，如果能装下则分为两部分，否则只看前面的物品价值
```cpp
for (int i = 1; i <= m; i++) {每一个物品都进行枚举
	for (int j = t; j >= 0; j--) {对每一个可能的容量都进行判断
		if (j >= l1[i].first) {
		如果当前剩余的容量还能装，那么进行判断
			dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - l1[i].first] +l1[i].second);
			
		}
		else {
		否则就向前面的进行看齐
			dp[i][j] = dp[i - 1][j];
		}
	}
}
```
当然也可以进行一维的代码优化，因为在这段代码中可以发现一维是不影响最终结果的
所以进行这样的优化
一维：dp[]中的维度表示剩余的时间，数值是剩余的价值
```cpp
for (int i = 1; i <= m; i++) {还是一样的遍历
	for (int j = t; j >= l1[i].first; j--) {但这一次部分能不能装，因为不分物品前后
	只考虑当前这个物品容量的时候能装的最大价值
		dp[j] = max(dp[j], dp[j - l1[i].first] + l1[i].second);进行选择
	}
}
```
同理类似的0/1背包的解决方式基本都是上述模板，只不过有时候关于dp[]的操作会变化

## 需要注意的点
0/1背包会出现这样的情况：背包有需求必须装满，此时需要把背包中所有容量令为-∞，因为这样就可以表示这个dp数组中所有背包只有装满的时候才能把这个dp的值由-∞转换为一个确定的值，具体的可以根据转移方程本身去看
而没有装满的限制只需要把每一个值变成0就行了，因为这时候每一个背包不装也是一种选择

完全背包
就是在0/1背包的基础之上进行变形，因为0/1背包在进行过程中需要考虑到前面的不能选，因此0/背包的第二次枚举是从后到前的。但是完全背包就没有这个困扰，可以直接从头开始枚举，大体上都是跟0/1背包的一致
一维：
```cpp
for (int i = 1; i <= m; i++) {
	for (int j = l1[i].first; j <= t; j++) {
		dp[j] = max(dp[j], dp[j - l1[i].first] + l1[i].second);进行选择
	}
}
```
这就是基础背包问题

# 取石子
在这里dp数组表示区间为[i,j]的答案
```cpp
for (int len = 2; len <= n; len++){
    for (int i = 1; i <= n - len + 1; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++) {
            dp[i][j] = max(dp[i][j], 
            dp[i][k] + dp[k + 1][j] + l1[j] - l1[i - 1]);
        }
    }
}
```
首先清楚区间DP也只是高效率枚举的一种方法，也就是通过枚举区间的长度以及区间的左边界实现逐渐覆盖所有可能的一种方法
在这里len表示区间长度，然后i从1开始进行逐渐向n枚举。j代表右边界，直接由i len可得，最后的k就相当于每一次区间的割点，因为是由小问题逐渐向大问题迈进。
这里的代码是题目中说明石子是一条直线的排列方式，如果说明石子是一个圈，则需要换种思路。
可以直接把原数组进行复制到2* n这个级别，现在能够把原问题简化为对于一个圈中的每一个可能出现点进行枚举，看谁是最大的那个点
因此需要对代码进行优化，简单来说只需要动一小部分
```cpp
for (int len = 2; len <= n; len++){
    for (int i = 1; i <= 2*n - len + 1; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++) {
            dp[i][j] = max(dp[i][j], 
            dp[i][k] + dp[k + 1][j] + l1[j] - l1[i - 1]);
        }
    }
}
```
也就是改变一下左半边的枚举范围，这样就实现了对一个圈中的各个数的枚举，同属要注意，原本排成一列之后的答案与形成圈之后的答案不同

# 抽取问题
给定一个区间，规定抽取规则，询问最大或者最小值
需要注意的点是在抽取是的状态转移方程中，可能会出现一点问题
```cpp
rep(len,3,n){
        rep(i,0,n-len){
            int j=i+len-1;
            rep1(k,i+1,j){
                dp[i][j]=min(dp[i][j],dp[i][k]+dp[k][j]+l1[k]*l1[i]*l1[j]);
                能够看到最后转移的条件中并不是简单的l1[k-1]*l1[k]*l1[k+1]
                而是直接乘上l1[i]*l1[k]*l1[j]
                这是因为dp[]数组的表示是在这一个区间中i，j是那两个没有被拿走的数
                这里的k表示最后被拿走的牌，如果k单单表示每一次拿走的牌
                那么这个dp方程就不对，因为会受到拿走牌之后的影响
                所以说在这里k是代表最后拿走的牌，因此才会出现这样的状态转移方程
            }
        }
    }
```

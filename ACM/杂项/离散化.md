首先遇见那种数据范围很大，基本上都是1e9这种级别的（或者是数据中出现负数这种情况的），但是实际上的数据量差不多1e5
那么这时候就需要用到离散化来帮助存储数据了
也算是一种对于特殊题目的特殊处理方法
本质上就是用一个简单的数组存储下标方便进行存储，而不需要更大的数据范围
实际代码可以是这样的
```cpp
for (int i = 1; i <= n; i++ ) {
		cin >> a1[i] >> b1[i];
		l1[2 * i - 1] = a1[i];
		l1[2 * i] = b1[i];
	}
	sort(l1 + 1, l1 + 2 * n + 1);
	for (int i = 1; i <= n; i++) {
		a1[i] = lower_bound(l1 + 1, l1 + 2 * n + 1, a1[i]) - l1;
		b1[i] = lower_bound(l1 + 1, l1 + 2 * n + 1, b1[i]) - l1;
		for (int j = a1[i]; j < b1[i]; j++) {
			f1[j] = 1;
		}
	}
```
首先就是原本数组应该是a1 b1 ，然后这时候整出来一个数组的副本，用来记录当前数组的值
之后将新的副本数组进行排序（去重）之后，再用原数组进行二分查找，找到在副本数组中的下标
这样就能实现很简单的进行查询操作，基本上都是用于区间等数据，也可以与并查集一起用
